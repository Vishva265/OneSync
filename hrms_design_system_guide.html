HRMS Website Design System Prompt Overall Vision: Clean, trustworthy, and data-forward. Think enterprise-grade but without feeling cold. The UI should feel like a premium SaaS product (think Rippling or Keka HR). Colors Primary palette — Navy-Blue corporate scheme: Deep Navy #0f2a52 → sidebar, navbar backgrounds Primary Blue #1a3c6e → primary buttons, active states, links Accent Blue #2563eb → highlights, focus rings, interactive hover Page Background #f0f4fa → very light blue-gray, never pure white for page bg Card Surface #ffffff → cards, modals, panels Border #e2e8f0 → all dividers and card edges Semantic colors — use these only for their meaning, never for decoration: Success #16a34a, Warning #f59e0b, Danger #dc2626, Info #2563eb Typography Use Inter as the only font (import from Google Fonts). Never mix fonts.
